# 상품 상세페이지 성분 패널 UI 리뷰

## 1. 전체 평가

현재 구현은 이전 화면보다 상품 이미지와 구매 정보의 균형이 크게 좋아졌다. 상품 상세페이지를 이탈하지 않고 성분 정보를 확인한 뒤 바로 구매 행동으로 돌아갈 수 있다는 점도 좋다.

특히 다음 구조가 의도대로 구현되었다.

- 상품 이미지를 적절한 크기로 제한
- 상품명 아래 효과 중심의 한 줄 평 배치
- 가격과 장바구니 버튼 사이에 성분 판정 카드 배치
- 페이지 이동 대신 우측 사이드 패널 사용
- 전체 성분표 대신 확인이 필요한 성분만 표시
- 배경 오버레이로 패널에 시선 집중

현재 상태는 **레이아웃과 상호작용의 기본 구조는 완성됐고, 성분 점수와 평가 근거의 표현을 보완해야 하는 단계**로 판단한다.

---

## 2. 잘된 부분

### 2.1 상품 이미지 크기

상품 이미지가 이전처럼 화면 전체를 차지하지 않는다. 상품명, 한 줄 평, 가격, 성분 판정, 장바구니 버튼이 첫 화면 안에서 함께 보인다.

### 2.2 구매 정보의 우선순위

오른쪽 구매 영역에 사용자가 구매를 결정하는 데 필요한 정보가 순서대로 배치되어 있다.

```text
브랜드
↓
상품명
↓
한 줄 평
↓
가격과 할인
↓
성분 판정
↓
장바구니
```

### 2.3 성분 패널 동작

별도 페이지로 이동하거나 상품 설명 하단까지 스크롤하지 않고, 현재 화면 위에서 주의 성분을 확인할 수 있다.

이 방식은 다음 장점이 있다.

- 구매 흐름이 끊기지 않는다.
- 패널을 닫으면 바로 장바구니 버튼을 누를 수 있다.
- 사용자가 상품 이미지와 기본 정보를 떠나지 않는다.
- 모바일에서는 같은 구조를 바텀시트로 자연스럽게 전환할 수 있다.

### 2.4 정보량 조절

전체 성분을 모두 나열하지 않고 글리콜릭애씨드와 락틱애씨드처럼 확인할 성분만 보여주는 방향이 서비스 목적에 적합하다.

## 3. 우선 수정 사항

## 3.1 `확인 성분` 문구 변경

현재 문구:

```text
확인 성분 2개
확인 성분 2개 보기
```

`확인 성분`은 한국어 문장으로 다소 어색하고, 무엇을 확인한다는 것인지 의미가 약하다.

권장 문구:

```text
확인이 필요한 성분 2개
성분 주의사항 보기
```

조금 더 짧은 문구가 필요할 경우:

```text
주의 성분 2개
주의 성분 2개 확인
```

서비스의 친절하고 단정적이지 않은 말투에는 `확인이 필요한 성분 2개`가 가장 적합하다.

---

## 3.2 성분별 주의도 표시

이전에 설계한 `0~3단계 성분 주의도`가 현재 패널에 보이지 않는다. 성분명 오른쪽에 작은 배지를 배치한다.

```text
글리콜릭애씨드                         주의도 2
```

권장 색상:

- 0단계: 중립적인 회색
- 1단계: 청록색 또는 파란색
- 2단계: 주황색
- 3단계: 진한 주황색
- 정보 부족 또는 검토 필요: 빨간색

숫자만 보여주면 사용자가 점수의 의미를 알기 어려우므로 패널 상단에 짧은 설명을 추가한다.

> 주의도가 높을수록 사용 조건을 더 확인해야 한다는 의미예요.

0단계가 완전한 안전을 의미하지 않는다는 안내도 평가 기준 영역에서 제공한다.

---

## 3.3 `근거: AHA` 수정

현재 문구:

```text
근거: AHA
```

AHA는 출처나 평가 근거가 아니라 성분의 분류다. 다음처럼 분리해야 한다.

```text
분류: AHA 계열
평가 근거: 식약처 공개자료 · 자체 평가 기준
```

평가 근거를 누르면 상세 내용을 펼쳐볼 수 있게 한다.

```text
[평가 근거 보기 ↓]

식약처 화장품 원료성분정보
식약처 화장품 사용제한 원료정보
자체 평가 기준 v1.0
최종 검토: 2026.07.25
```

실제 공식 출처와 아직 연결되지 않은 데모 데이터라면 다음처럼 표시한다.

```text
평가 근거: 포트폴리오용 데모 데이터
```

출처가 준비되지 않은 상태에서 식약처 자료를 사용했다고 표시하면 안 된다.

---

## 3.4 성분별 설명 차별화

현재 글리콜릭애씨드와 락틱애씨드 설명이 완전히 동일하다. 이렇게 표시하면 데이터가 아니라 동일한 문장 템플릿을 반복한 것처럼 보인다.

각 성분의 역할과 확인 사항이 다르게 보이도록 작성한다.

예시:

```text
글리콜릭애씨드                         주의도 2
AHA · 각질 관리

각질과 피지를 정돈하기 위해 들어갔어요.
민감하거나 건조한 피부는 따가움을 느낄 수 있어요.
```

```text
락틱애씨드                             주의도 1
AHA · 각질 관리

각질을 부드럽게 정돈하고 수분 유지에 도움을 줘요.
예민한 피부는 사용 빈도를 조절해보세요.
```

위 문구와 점수는 예시이므로, 실제 구현에서는 적용한 공식 자료와 자체 평가 기준에 맞춰야 한다.

---

## 3.5 메인 성분 판정 카드 보완

현재:

```text
● 대체로 무난해요

확인 성분 2개 보기 →
```

현재 문구만으로는 왜 무난한지, 어떤 사용자가 성분을 확인해야 하는지 알기 어렵다.

권장 구성:

```text
● 대체로 무난해요

각질 관리에는 적합하지만,
민감하거나 건조한 피부는 성분 2개를 확인해보세요.

[확인이 필요한 성분 2개 →]
```

사용자는 패널을 열지 않아도 다음 내용을 이해할 수 있어야 한다.

- 제품이 제공하는 효과
- 확인이 필요한 사용자
- 확인이 필요한 성분 개수

---

## 3.6 효과 태그 추가

상품명 아래 한 줄 평은 잘 들어갔지만, 대표 효과를 빠르게 읽을 수 있는 태그가 없다.

권장 예시:

```text
[각질 정돈] [매일 한 장] [민감 피부 주의]
```

색상 구분:

- 효과 태그: 청록색 또는 중립색
- 사용감 태그: 회색
- 주의 태그: 주황색

태그는 최대 3~4개만 사용한다. 너무 많은 태그를 넣으면 성분표처럼 복잡해진다.

현재 표시된 `GIFT`가 핵심 상품 정보가 아니라면 효과 태그보다 시각적 우선순위를 낮춘다.

## 6. 패널 UI 세부 권장 사항

### 6.1 패널 너비

- 데스크톱: `420~480px`
- 모바일: 화면 너비 전체의 바텀시트

현재 패널 너비는 큰 화면에서 읽기에 충분하다. 텍스트 한 줄이 지나치게 길어지지 않도록 본문 콘텐츠 영역에는 좌우 여백을 유지한다.

### 6.2 헤더 고정

성분이 많아 패널 내부를 스크롤하더라도 다음 요소는 상단에 고정한다.

- 패널 제목
- 성분 개수
- 닫기 버튼

### 6.3 닫기 동작

- 닫기 버튼 클릭
- 패널 바깥 영역 클릭
- `Esc` 키 입력
- 모바일에서 아래로 드래그

패널이 닫히면 키보드 포커스가 `확인이 필요한 성분 2개` 버튼으로 돌아가게 한다.

### 6.4 스크롤

패널이 열려 있는 동안 배경 페이지 스크롤을 잠근다. 패널 내용이 화면보다 길면 패널 내부만 스크롤한다.

### 6.5 접근성

- 패널에 `role="dialog"` 사용
- `aria-modal="true"` 적용
- 패널 제목을 `aria-labelledby`로 연결
- 키보드 포커스를 패널 내부에 유지
- 색상뿐 아니라 `주의도 2`와 같은 텍스트로 상태 전달

## 7. 권장 문구 비교

| 현재 또는 피해야 할 문구 | 권장 문구 |
|---|---|
| 확인 성분 2개 | 확인이 필요한 성분 2개 |
| 확인 성분 2개 보기 | 성분 주의사항 보기 |
| 근거: AHA | 분류: AHA 계열 |
| 안전한 성분 | 별도 제한 정보가 확인되지 않은 성분 |
| 위험 성분 | 확인이 필요한 성분 |
| 유해성 2점 | 성분 주의도 2단계 |
| 피부에 자극을 줍니다 | 피부에 따라 자극을 느낄 수 있어요 |

## 8. 수정 우선순위

### 1순위

- 성분명 옆에 `주의도 0~3` 배지 추가
- `확인 성분`을 `확인이 필요한 성분`으로 변경
- `근거: AHA`를 성분 분류와 실제 평가 근거로 분리

### 2순위

- 성분마다 서로 다른 역할과 주의사항 작성
- 메인 성분 카드에 확인 대상과 이유 추가
- 평가 근거 펼치기 기능 추가

### 3순위

- 한 줄 평 아래 효과 태그 추가
- 패널 하단에 평가 안내 문구 추가
- 포커스 복귀, `Esc` 닫기 등 접근성 보완

## 9. 최종 결론

현재 화면은 상품 이미지 크기, 구매 정보 배치, 성분 패널 방식이 모두 적절하다. 특히 우측 사이드 패널은 구매 흐름을 유지하면서 성분 정보를 제공한다는 서비스 목적에 잘 맞는다.

다음 세 가지를 보완하면 성분 패널이 단순한 설명 창에서 서비스의 핵심 기능으로 발전할 수 있다.

1. 성분별 `0~3단계 주의도` 표시
2. 성분마다 다른 이유와 사용자별 주의사항 제공
3. 분류와 실제 평가 근거를 구분해 출처 명시

점수 자체보다 사용자가 다음 질문에 빠르게 답을 얻도록 설계하는 것이 중요하다.

- 이 성분은 왜 들어갔는가?
- 누가 확인해야 하는가?
- 이 제품에서는 어떻게 해석해야 하는가?
