# 남성 화장품 상품 상세페이지 UX 기획

## 1. 서비스 방향

이 서비스는 단순히 남성용 상품을 모아 판매하는 쇼핑몰이 아니라, 화장품에 익숙하지 않은 남성도 제품의 효과와 주의점을 빠르게 이해하고 구매할 수 있도록 돕는 것을 목표로 한다.

핵심 가치는 성분명을 많이 보여주는 데 있지 않다. 복잡한 성분 정보를 사용자가 이해할 수 있는 **효과, 판정, 주의사항**으로 해석해 주는 데 있다.

서비스를 한 문장으로 표현하면 다음과 같다.

> 화장품을 몰라도 실패하지 않게 골라주는 남성 그루밍 스토어

사용자가 상품 상세페이지에서 빠르게 답을 얻어야 하는 질문은 다음과 같다.

- 이 제품을 쓰면 어떤 효과가 있는가?
- 어떤 피부 타입에 적합한가?
- 사용감이나 세정력은 어떤가?
- 내 피부가 주의할 부분이 있는가?
- 결국 안심하고 구매해도 되는가?

---

## 2. 현재 화면의 주요 문제

### 2.1 상품 이미지가 지나치게 크다

현재 상품 이미지가 화면의 절반 이상을 차지하며 세로로도 길게 늘어나 있다. 이로 인해 상품명, 가격, 효과, 성분 정보가 주변 정보처럼 보인다.

상품 이미지는 제품을 확인할 수 있을 정도로만 보여주고, 구매 결정에 필요한 정보를 첫 화면 안에 함께 배치해야 한다.

### 2.2 오른쪽 구매 영역의 정보 밀도가 낮다

상품명, 가격, 장바구니 버튼만 작게 배치되어 있고 나머지 공간이 비어 있다. 서비스의 핵심 차별점인 효과 안내와 성분 판정이 첫 화면에서 보이지 않는다.

### 2.3 성분 정보가 이미지 아래에 묻혀 있다

현재의 작은 성분 태그만으로는 사용자가 제품의 안전성이나 주의점을 판단하기 어렵다. 성분 정보가 서비스의 핵심이라면 가격과 장바구니 버튼에 가까운 위치에서 보여야 한다.

### 2.4 구매에 필요한 결론이 없다

사용자는 개별 성분명보다 먼저 “그래서 이 제품이 나에게 어떤 도움을 주는가?”를 알고 싶어 한다. 현재 화면에는 이를 즉시 설명하는 한 줄 결론이 없다.

## 3. 설계 원칙

상품 상세페이지의 정보는 다음 순서로 이해되어야 한다.

1. 제품이 주는 대표 효과
2. 추천 피부 타입과 사용감
3. 가격과 할인 정보
4. 성분 기준의 종합 판정
5. 주의 성분과 그 이유
6. 구매 행동

전체 성분 목록은 제공하지 않는다. 사용자가 성분을 직접 공부하게 하기보다, 구매에 영향을 주는 주의 성분만 선별해 이해하기 쉬운 언어로 설명한다.

또한 화장품 성분은 함량, 제품 유형, 사용 부위, 개인의 피부 상태와 알레르기 여부에 따라 다르게 작용할 수 있으므로 `안전`과 `위험`으로 단정하지 않는다.

권장 판정 표현은 다음과 같다.

- 걱정 성분이 거의 없어요
- 대체로 무난해요
- 민감한 피부는 확인이 필요해요
- 주의가 필요한 성분이 있어요

## 4. 첫 화면의 권장 구조

### 4.1 데스크톱 레이아웃

```text
┌────────────────────────┬──────────────────────────────┐
│                        │ 브랜드명                     │
│                        │                              │
│      상품 이미지        │ 상품명                       │
│      520 × 520          │ 퓨어그루브 딥클렌징폼 150ml   │
│                        │                              │
│                        │ 한 줄 평                      │
│                        │ 번들거림과 묵은 각질을         │
│                        │ 개운하게 씻어내는              │
│                        │ 지성 피부용 클렌저              │
│                        │                              │
│                        │ [피지 관리] [각질 케어]         │
│   ○   ○   ○ 썸네일      │ [강한 세정력] [민감 피부 주의] │
│                        │                              │
│                        │ 30%  9,800원                  │
│                        │                              │
│                        │ ┌──────────────────────────┐ │
│                        │ │ ● 대체로 무난해요          │ │
│                        │ │ 주의 성분 3개가 있지만     │ │
│                        │ │ 씻어내는 제품이에요.       │ │
│                        │ │                          │ │
│                        │ │ [주의 성분 3개 확인 →]     │ │
│                        │ └──────────────────────────┘ │
│                        │                              │
│                        │ [     장바구니 담기       ]   │
└────────────────────────┴──────────────────────────────┘
```

### 4.2 권장 크기

- 전체 콘텐츠 최대 너비: `1180~1280px`
- 상품 이미지 최대 너비: `520~600px`
- 구매 정보 영역 너비: `420~480px`
- 장바구니 버튼 높이: `52~56px`
- 상품명 크기: `24~28px`
- 최종 가격 크기: 약 `24px`

상품 이미지가 원본 비율에 따라 지나치게 커지지 않도록 이미지 컨테이너를 고정한다.

```css
.product-image {
  width: 100%;
  max-width: 560px;
  aspect-ratio: 1 / 1;
  object-fit: contain;
  background: #f7f7f7;
}
```

기본 이미지는 제품 용기가 잘 보이는 정면 사진을 사용한다. 분위기를 보여주는 연출 사진은 두 번째 이후 썸네일에 배치한다.

## 5. 한 줄 평

### 5.1 역할

한 줄 평은 상품명 바로 아래, 가격보다 위에 배치한다. 사용자가 상품을 본 직후 “그래서 이 제품을 쓰면 무엇이 좋은가?”에 답하는 가장 중요한 문장이다.

한 줄 평과 성분 판정의 역할은 구분한다.

- 한 줄 평: 제품의 효과와 추천 대상을 알려준다.
- 성분 판정: 사용 시 확인해야 할 주의점을 알려준다.

### 5.2 작성 공식

> `[주요 효과] + [사용감 또는 추천 대상]`

좋은 예시는 다음과 같다.

- 번들거림과 묵은 각질을 개운하게 씻어내는 지성 피부용 클렌저
- 세안 후 당김을 줄이고 촉촉함을 남기는 건성 피부용 클렌저
- 면도 후에도 부담이 적은 순한 데일리 수분크림
- 끈적임 없이 유분을 잡아주는 지성 피부용 선크림
- 트러블 흔적과 붉은기를 함께 관리하는 진정 세럼

`피부를 깨끗하게 해주는 클렌저`처럼 대부분의 상품에 붙일 수 있는 추상적인 표현은 피한다.

### 5.3 효과 태그

한 줄 평 아래에는 대표 효과를 최대 3~4개의 태그로 압축해 보여준다.

```text
[피지 관리] [각질 케어] [강한 세정력]
[민감 피부 주의]
```

효과와 주의 태그는 시각적으로 구분한다.

- 청록색: 피지 관리, 각질 케어 등 주요 효과
- 회색: 산뜻함, 촉촉함 등 사용감
- 주황색: 민감 피부 주의 등 확인이 필요한 내용

효과 태그가 많아지면 성분표처럼 복잡해지므로 대표 효과만 선택한다.

---

## 6. 성분 판정 카드

성분 판정 카드는 가격 아래, 장바구니 버튼 위에 배치한다.

```text
● 대체로 무난해요
주의 성분 3개가 있지만 씻어내는 제품이에요.

[주의 성분 3개 확인 →]
```

첫 화면에서는 다음 정보만 보여준다.

- 이해하기 쉬운 종합 판정
- 주의 성분 개수
- 제품 유형을 고려한 한 줄 설명
- 주의 성분 확인 버튼

`고위험 성분 Free`처럼 의미가 모호하거나 영어가 섞인 표현보다 `고위험 판정 성분 0개`처럼 정확한 한국어를 사용한다.

다만 숫자를 지나치게 강조하면 성분의 실제 위험을 정밀하게 계산한 것처럼 오해할 수 있으므로, 숫자는 판정의 보조 정보로 사용한다.

---

## 7. 주의 성분 확인 패널

### 7.1 기본 동작

`주의 성분 3개 확인` 버튼을 눌렀을 때 페이지 하단으로 이동하거나 새 페이지로 전환하지 않는다. 사용자가 상품과 구매 정보를 보던 흐름을 유지한 상태에서 별도의 패널을 띄운다.

- 데스크톱: 화면 오른쪽에서 나타나는 사이드 패널
- 모바일: 화면 아래에서 올라오는 바텀시트
- 전체 성분 목록: 제공하지 않음
- 패널 내용: 주의 성분과 이유만 제공

### 7.2 데스크톱 사이드 패널

```text
기존 상품 페이지                  주의 성분 패널
┌───────────────────────┬─────────────────────┐
│                       │ 주의 성분 3개     × │
│                       │                     │
│ 상품 이미지와          │ 민감하거나 건조한   │
│ 구매 정보              │ 피부라면 확인하세요. │
│                       │ 이 제품은 씻어내는   │
│                       │ 클렌저입니다.        │
│                       │                     │
│                       │ 살리실산             │
│                       │ 각질과 피지를        │
│                       │ 정리하기 위해        │
│                       │ 들어갔어요.          │
│                       │                     │
│                       │ 향료                 │
│                       │ 제품에 향을 더하는   │
│                       │ 성분이에요.          │
└───────────────────────┴─────────────────────┘
```

권장 사양은 다음과 같다.

- 패널 너비: `420~480px`
- 화면 오른쪽에 고정
- 기존 화면 위에 옅은 검은 오버레이 표시
- 패널 내부만 스크롤
- 닫기 버튼, 바깥 영역 클릭, `Esc` 키로 닫기
- 패널을 닫으면 기존에 눌렀던 버튼으로 포커스 복귀

### 7.3 모바일 바텀시트

모바일에서는 화면 높이의 약 `70~85%`를 차지하는 바텀시트가 적합하다.

- 아래에서 위로 나타남
- 내부 내용만 스크롤
- 아래로 드래그하여 닫기
- 닫기 버튼과 바깥 영역 터치로도 닫기
- 제목과 닫기 버튼은 상단에 고정

작은 팝오버는 성분 설명이 길어졌을 때 답답하고 읽기 어려우므로 사용하지 않는다.

## 8. 주의 성분 설명 방식

각 성분은 전문적인 정의보다 구매 판단에 필요한 세 가지 정보만 설명한다.

1. 왜 넣었는가?
2. 누가 주의해야 하는가?
3. 이 제품에서는 어떻게 봐야 하는가?

패널 예시는 다음과 같다.

```text
주의 성분 3개                                  ×

민감하거나 건조한 피부라면 확인해보세요.
이 제품은 씻어내는 클렌저입니다.

살리실산                                  각질 관리
각질과 피지를 정리하기 위해 들어갔어요.
민감하거나 건조한 피부에는 자극이 될 수 있어요.
이 제품은 씻어내는 제품이에요.

향료                                          향
제품에 향을 더하기 위해 들어갔어요.
향에 예민하거나 알레르기가 있다면 확인하세요.

에탄올                                  산뜻한 사용감
끈적임을 줄이고 산뜻한 사용감을 만들어요.
건조한 피부는 당김을 느낄 수 있어요.
```

성분 설명은 짧고 일상적인 언어로 작성한다. 사용자가 다시 검색해야 이해할 수 있는 전문용어는 피한다.

## 9. 최종 정보 우선순위

상품 상세페이지 오른쪽 구매 영역은 다음 순서를 따른다.

```text
브랜드명
↓
상품명
↓
한 줄 평
↓
핵심 효과 태그 3~4개
↓
가격과 할인
↓
성분 판정 카드
↓
주의 성분 확인 버튼
↓
장바구니 버튼
```

가장 중요한 두 문장은 다음과 같은 관계를 가진다.

> 번들거림과 묵은 각질을 개운하게 씻어내는 지성 피부용 클렌저

> 대체로 무난하지만 민감한 피부가 확인할 성분 3개가 있어요.

첫 번째 문장은 제품의 효과를 알려주고, 두 번째 문장은 구매 전에 알아야 할 주의점을 알려준다. 사용자는 이 두 문장만 읽어도 제품의 장점과 주의사항을 빠르게 이해할 수 있어야 한다.

---

## 10. 최종 결정 사항

- 상품 이미지는 최대 `520~600px` 범위로 제한한다.
- 첫 화면 상단에 효과 중심의 한 줄 평을 배치한다.
- 한 줄 평 아래에는 대표 효과 태그를 최대 3~4개 표시한다.
- 성분 판정은 가격 아래, 장바구니 버튼 위에 배치한다.
- 전체 성분 목록은 보여주지 않는다.
- 사용자가 확인할 필요가 있는 주의 성분만 제공한다.
- 각 주의 성분은 들어간 이유, 주의 대상, 제품 유형을 고려한 설명을 제공한다.
- 주의 성분 버튼을 누르면 페이지 이동이나 하단 스크롤 대신 별도 패널을 표시한다.
- 데스크톱에서는 우측 사이드 패널, 모바일에서는 바텀시트를 사용한다.
- `안전 보장`처럼 단정적인 표현보다 `대체로 무난해요`, `확인이 필요해요`와 같은 안내형 표현을 사용한다.
